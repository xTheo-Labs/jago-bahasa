# Jago Bahasa

An offline-first Progressive Web App for learning 23 world languages, from first words to CEFR exams.

| | |
|---|---|
| **Status** | Beta |
| **Platform** | Any modern browser; installs as an app on desktop and mobile |
| **App** | <https://jago-bahasa.vercel.app> |
| **Interface** | Indonesian, English, Spanish |

## Overview

Jago Bahasa teaches 23 languages through short lessons, a print-style dictionary, practice drills, and CEFR stage exams with printable certificates. After the first visit it keeps working with no connection. It is built with plain HTML, CSS, and JavaScript modules, with no framework and no third-party runtime dependency.

## Features

- **23 languages**, 442 lessons, and 3,563 lesson words.
- **Dictionary**: 3,864 entries tagged with CEFR levels A1–C2, browsed A–Z by each language's own script (Hangul, Thai, Arabic, romaji, pinyin).
- **Practice modes**: flashcards, quiz, typing, dictation, listening, matching, cloze, sentence builder, speaking, and a script trainer.
- **Spaced repetition** across lesson words and starred dictionary entries.
- **Exams and certificates**: stage exams with an 80% pass mark and a cross-stage final, with one-page certificates.
- **Honest audio**: languages the device cannot pronounce are marked instead of being read with the wrong voice.
- **Private by default**: accounts and progress stay on the device; progress can be exported as JSON.

## Quality

- 161 automated tests, including browser tests that drive real Chrome, run in CI on Node 20 and 22.
